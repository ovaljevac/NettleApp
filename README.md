# 🌿 NettleApp (AR Experience)

**NettleApp** is an augmented reality (AR) mobile application that allows users to explore **nettle (Urtica dioica)** through an immersive, interactive kitchen scene. By scanning a physical target with the device camera, users enter an AR environment where a **3D nettle model**, created in **Blender**, is displayed as the central element.

The application combines **education, multimedia content, and gamification** to present nettle in an engaging and informative way.

---

## 🚀 Core Features

### 📷 AR Target Scanning
- Users scan a predefined **image target** using the device camera
- Once detected, an **AR kitchen scene** is rendered
- The experience is anchored to the real-world environment

### 🌱 3D Nettle Model
- High-quality **3D model of nettle**, modeled in **Blender**
- Placed as the **central object** in the AR kitchen scene
- Optimized for mobile AR performance

### 📍 Points of Interest (POI)
- Interactive **POI objects** placed around the scene
- Each POI can be tapped to open:
  - 🎥 Video content  
  - 🔊 Audio recordings  
- Media content is directly related to:
  - Nettle usage
  - Health benefits
  - Culinary and traditional applications

### 🧠 Knowledge Quiz
- Accessible from the **Main Menu**
- Interactive **quiz about nettle**
- Designed to test and reinforce user knowledge
- Provides instant feedback to the user

### ℹ️ Info Panel
- Dedicated **information panel** with additional educational content
- Presents structured facts and explanations about nettle
- Accessible independently from the AR scene

---

## 🧭 Application Structure

### Main Menu
The main menu provides access to:
- **Start AR Experience**
- **Knowledge Quiz**
- **Info Panel**

### AR Scene Flow
1. User launches AR mode
2. Camera scans the target image
3. AR kitchen scene appears
4. User interacts with:
   - 3D nettle model
   - POI objects (video/audio)
5. User can return to the main menu at any time
